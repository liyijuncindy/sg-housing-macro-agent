# GLM 真实运行与人工复核

本说明与模型原文分开保存。报告状态 `complete` 表示通过程序的结构、数据和证据检查，不代表自由文字已经获得人工批准，更不表示指标具有已验证的预测能力。

## 首轮：新鲜取数与接入验证

`siliconflow_glm_verified_run` 使用提交 `94e477b`，从 SingStat 发起 41 次请求并成功获取全部 16 个候选，未使用备用来源或旧快照。独立核对了 2,318 个原始观测、23 项变化计算和全部文件哈希，没有发现差异。模型实际使用 `zai-org/GLM-5.3`，调用 3 次，输入 32,677、输出 11,604，共 44,281 tokens；其中推理 8,197 已包含在输出中。端到端 253.796 秒，模型部分 158.238 秒。

模型为全部 16 项给出了自己的理由，选入 SORA、住房及过桥贷款余额、已建成私人住宅存量、空置私人住宅数量和居民住户数。空置数量与存量具有分子/分母的互补性，允许同属供应类别的两项同时入选；程序本次没有派生或计算空置率。没有选入收入、劳动力、宏观活动和通胀，不代表这些类别没有独立信息。

首轮需要以下人工修正，原始输出保持不变：

- 失业率属于尚未覆盖的 `labour_market` 类别，不能声称它不增加独立类别覆盖；限额取舍应明确承认这个代价。
- 空置住房不等于已挂牌或可立即出租的住房，空置数量也不等于空置率。
- 季度观察频率不证明滞后一季发布。未核验的发布延迟不应被当成事实。
- 住户统计在已提供资料中列出人口普查、住户调查及六月劳动力调查；模型额外加入行政资料的说法未获本次证据支持。住户净变动无法拆出形成、解散等毛流量，但净变动本身并非忽略解散。
- 本项目未实现或验证跨频率插值、平滑和房价预测模型，不能把这些建议或“边际模型价值”当成实测结论。
- 贷款统计历史报告制度变更应根据明确日期与实际保留窗口核对，不能未经核对声称发生在当前窗口中间。
- CPI 的含糊“相对基期较小”描述没有明确可检验含义，不能作为排除依据。

详见[首轮语义审计](evidence/siliconflow-glm-semantic-audit.json)、[独立数据审计](evidence/siliconflow-glm-data-audit.json)和[首轮原始报告](../examples/siliconflow_glm_verified_run/report.md)。首轮按官方价格和已报告缓存用量估算为人民币 0.547544 元，含两次小探测共 0.553320 元；这不是已读取的账户扣费账单。

针对上述问题，后续指令要求事实严格来自给定元数据，区分观察频率与发布延迟、空置与挂牌、存量与形成，并对照真实入选类别解释排除理由。指令改进仍需真实复核，不能仅凭新增提示文字证明所有未来输出都正确。


## 第二轮：同快照复跑与最终说明

`siliconflow_glm_reviewed_run` 使用干净提交 `0cdb5a4`，显式复用第一轮的新鲜数据快照。保留原始获取时间并重新计算数据检查，**没有再次访问数据源**。源文件、数值和计算均由[第二轮独立审计](evidence/siliconflow-glm-final-data-audit.json)验证。

本次选择了 SORA、居民住户数、居民就业住户收入中位数、居民失业率和私人住宅空置数，覆盖五个不同的经济类别。3 次模型调用，30,125 输入 + 7,788 输出 = 37,913 tokens；5,126 推理 token 已包含在输出中。总耗时 95.345 秒，按返回缓存量估算人民币 0.417976 元。

最终状态 `complete_with_warnings` 包含两项明示提醒：本次未刷新来源；模型缺少 HDB 存量的逐项排除理由，系统只补上“未选择且未解释”的事实，不能代替模型给出经济判断。其余十五项理由由模型提供，五项入选和引用均通过检查。

首轮的固定发布滞后、行政来源延伸、空置等于挂牌房源，以及插值建议已不再出现在第二轮原文中。仍应按下列人工说明阅读：

- 非居民人口序列未提供租赁占比，不能据此断言非居民“主要是租客”；是否租赁、宿舍居住等应保留为待核验条件。
- 居民住户存量变化无法单独识别毛新增、解散、成员重组和分类变化，宜表述为“净变化不能替代毛新增住户数”，不宜无条件断言它必然低估新成立住户。
- 私人住宅存量与空置数同属 `housing_supply`。补上存量会增加分母背景，不会增加新的经济类别；“增量信息少”也没有经过预测检验。
- 本次没有选择配套存量，更没有计算空置率。空置数量的涨跌不等于空置率或市场紧张程度同向变化，解释必须保留分母限制。
- 住户中位数、个人平均收入、国民账户总收入是三种不同口径，原文“aggregate per-person alternatives”措辞不清。最终中位数叙述已说明其范围是至少有一名就业成员的居民住户，不能泛指所有住户或每个人。

本轮没有训练预测模型、估计相关性或开展样本外检验。选择理由是经济机制和覆盖取舍，不证明这五项是最优预测组合。完整逐项检查见[第二轮语义审计](evidence/siliconflow-glm-final-semantic-audit.json)。
