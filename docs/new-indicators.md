# 候选指标扩展记录

2026 年 10 月 1 日，本轮将候选池从 **12 项扩展为 16 项**。先通过官方资源检索缩小范围，再实际下载并评估六条序列，新增其中四条；其余两条保留为研究候选。新增依据是覆盖缺口、明确口径和数据可用性，**尚未完成相关性、因果或预测能力验证**，也不保证新增指标会在每次运行中入选。

SingStat API 成功请求时间为新加坡时间 **19:23:16—19:26:26**。检索关键词为 `household`、`employment`、`residential transactions`、`HDB` 和 `sales`。初始受限网络中的域名解析失败也保留在检索记录，随后获准访问官方网络并成功获取原始响应。这不是全量指标搜索，只是围绕当前覆盖缺口的有限候选审查。

## 参考日与就业覆盖核验

HDB 表的官方总脚注明确为每年六月末，因此 `reference_month_day=06-30`。就业行名称明确为年末，因此使用 `12-31`。住户数表只有调查来源说明，没有证明每个普查和调查年度都采用同一个精确日历参考日，因此不套用人口表的六月末设定；程序使用保守年末截点进行年度过滤，**这不是实际测量日期的声明**。收入年度值也没有被赋予推测的日内参考时点。

M183111 的原行脚注仅说明行政记录与自雇者的劳动力调查估计，不能单靠该脚注推出家政工人或国民服役的排除规则。因此另外核对了 [MOM 就业统计总表](https://stats.mom.gov.sg/Pages/employment-Summary-Table.aspx)：SingStat 的 2025 年值 4,117.0 千人与 MOM 的 `Total` 对应，同页 `Total (excl MDW)` 为 3,800.1 千人。由此确认本次匹配的是**包含外籍家政工人**的总量，不能拿排除家政工人的新闻标题口径替代。[MOM 行政记录覆盖说明](https://stats.mom.gov.sg/SL/Pages/Employment-Administrative-Records-Source-and-Coverage.aspx) 另明确覆盖居民雇员、持有效准证的非居民及自雇人士，排除两年全职国民服役人员。两页原始 HTML、获取时间和哈希另行保存；这是来源解释的佐证，不是新建 MOM 自动取数路径。

年度门槛为至少 3 个有效点、季度为至少 8 个；窗口完整率门槛为 75%，最近可用点的最大滞后分别为 2 年和 3 季度。季度净增量相对截止日的最近已结束季度滞后一季；其余四个新增年度指标均通过各自时效门槛。评分只表示数据可用性，年度 100 分不意味着它比季度数据更适合短期预测。

住房成交活跃度方面，本次有限关键词检索没有找到可直接确认口径并接入的相应时间序列表，因此没有用零值或无关销售指标代替，也不据此断言 SingStat 不提供此类数据。后续可专门研究 URA/HDB 官方交易来源。

房价与租金指数应先作为未来预测评估的目标，独立定义预测期限和防止信息泄漏。例如官方检索已出现 [HDB 转售价格指数 M212161](https://tablebuilder.singstat.gov.sg/table/TS/M212161)，本次没有将其混入已验证的预测因子；私人房价和租金目标的详细序列核验留待该阶段。

## 可复核证据

所有本次材料位于 [evidence/candidate-expansion](evidence/candidate-expansion/)：

- `retrievals.json`：官方请求 URL、时间、失败或成功状态与原始文件哈希。
- `raw/`：完整官方资源检索结果、七张已查看的元数据表、六条精确行数据，以及两页 MOM 覆盖佐证；七张元数据中的分行业就业表仅用于定位总就业序列，未新增分行业指标。
- `candidate_specs.json`、`normalized.json`、`evaluations.json`：六候选的口径配置、真实标准化观测与现有质量引擎输出。
- `assessment_summary.json`：六项逐一列明新增或暂缓决定、理由、最新参考期及质量详情。
- `employment_scope_sources.json`、`evidence_inventory.json`：额外覆盖证据的来源记录及本目录文件完整性清单。

目录中的计划取数入口统一使用 SingStat 官方表；每次运行记录的实际来源仍具有优先权。旧 MOM/MAS 直连运行、旧样例观测及原始来源元数据没有被改写。表更新时间不等于每条观测首次公布时间；这些当前快照不能还原历史时点的信息集。
