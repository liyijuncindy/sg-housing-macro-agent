## 模型原文应如何理解

最终模型选择了实际 GDP、居民失业率、居民平均就业收入、SORA 和居民住户数。其余 11 项虽全部数据合格，模型没有给出逐项排除理由；报告明确标为系统补充，**不能据此认为模型已证明这些指标不重要或重复**。

1. **居民住户数的分组。** 原文称其在某种意义上被排除于人口需求组，这个说法不正确。实际配置始终是 `population_demand`，与居民人口、非居民人口共组。独立序列 ID 不代表独立经济分组；模型文字没有修改程序配置。
2. **住户存量与住户形成。** 原文时滞段使用“Annual household formation”，应理解并改述为“年度居民住户存量提供结构性需求背景”。本序列不是当年新成立住户流量，其增量也不能直接当作毛新增住户数。原始定义和数值均保持存量口径。
3. **平均收入与中位数。** 原文说平均就业收入与住户收入中位数互补，只能作为一般的口径比较；本次报告没有选入住户中位数，也没有完成两者预测价值的比较验证。前者是每名就业居民的平均就业收入、含雇主 CPF 不含奖金；新增后者是居民就业住户的每户中位数、含雇主 CPF 和年度奖金分摊，不能互换。
4. **分组表述与利率渠道。** 失业率属于 `labour_market`，SORA 属于 `financing_cost`；原文“不属于收入组/通胀组”是笨拙的分组描述，不是把这两项排除于本次报告。SORA 是利率基准，实际房贷成本还取决于利差、固定或浮动条款和重设日期，不能理解为机械的一比一传导。
5. **收入历史范围。** 本次保存的季度平均就业收入历史自 2021 年第二季度起。模型修正后改用了“历史定义和覆盖变化可能限制可比性”的通用提醒，但本次证据没有确认该序列发生过具体的定义变更；这句话不能当作已核实的统计断点，也不证明更早数据不存在。

以上说明是人工审阅，不能冒充模型自己完成的纠错。模型的数字与证据约束降低了编造风险，**没有证明自由文字的语义一定准确**。
